# ⚡ Бот уведомлений об отключении света в Запорожье

Telegram-бот на Python, который отслеживает графики почасовых отключений (ГПВ) от **АТ «Запоріжжяобленерго»** и автоматически предупреждает перед отключением электроэнергии, при включении света и при обновлении графика.

## Возможности

- **Авто-предупреждение перед отключением**: за `5 / 10 / 15 / 30 / 60` минут до начала отключения (настраивается в `/settings`).
- **Уведомление о включении света**: напоминает, когда свет должен появиться по графику (можно отключить).
- **Уведомление об изменениях графика**: как только энергетики обновляют график на сегодня или публикуют график на завтра, бот присылает обновление.
- **Точность до 30 минут**: учитывает получасовые сдвиги (`first` / `second`, например `05:30 – 10:30`), а также объединяет переходы через полночь.
- **Быстрый просмотр статуса**: команды `/now`, `/today`, `/tomorrow` и удобные кнопки внизу экрана.
- **Надёжность**: сохраняет настройки и историю отправленных уведомлений в SQLite (`data/bot.db`), использует резервный источник данных и локальный кэш.

## Источники данных

1. Основной: [`milkmann/gpv-zoe-zaporizhzhia`](https://github.com/milkmann/gpv-zoe-zaporizhzhia) (агрегирует официальные данные с `zoe.com.ua/outage/` и официального Telegram-канала ЗОЕ).
2. Резервный: [`yaroslav2901/OE_OUTAGE_DATA`](https://github.com/yaroslav2901/OE_OUTAGE_DATA).

## Быстрый запуск

### 1. Создайте бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте выданный токен.

### 2. Настройте `.env`
```bash
cd /Users/maksim/Desktop/zaporizhzhia-svitlo-bot
cp .env.example .env
```
Откройте `.env` и вставьте ваш токен в `BOT_TOKEN=...`.

### 3. Установите зависимости (если нужно) и запустите
```bash
python3 -m pip install -r requirements.txt
python3 bot.py
```

### 4. Откройте бота в Telegram
Нажмите **Start** (`/start`) и выберите вашу очередь (от `1.1` до `6.2`).
Если не знаете свою очередь — в сообщении есть кнопка-ссылка на официальную проверку по адресу на `zoe.com.ua/outage/`.

## Автозапуск на macOS (чтобы бот работал в фоне 24/7)

Вы можете запускать бота через `nohup` или настроить `launchd` (подробный пример в `bot.py` / `launchctl`):
```bash
nohup python3 /Users/maksim/Desktop/zaporizhzhia-svitlo-bot/bot.py > data/bot.log 2>&1 &
```
